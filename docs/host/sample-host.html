🎓 Sample Host — Nhúng Widget VisualizationDSA

Trang này mô phỏng 1 website/LMS host bên ngoài domain của VisualizationDSA để kiểm chứng luồng cross-origin: auto-height (HEIGHT_CHANGED) + điều khiển host (STEP_FORWARD/PLAY_PAUSE) + quiz hoàn thành (QUIZ_COMPLETED).

1. Bước chạy (browser thật)

  1. Chạy app VisualizationDSA ở domain A (vd localhost:5173).
  2. Mở /#/embed-widget trong app, cấu hình thuật toán, sao chép mã iframe.
  3. Dán iframe vào <div id="widget-slot"> bên dưới (giữ data-embed-widget).
  4. Mở trang này ở domain B (vd file:// hoặc localhost:5500) -> xem log cross-origin bên dưới.
